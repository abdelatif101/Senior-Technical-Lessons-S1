
# Senior-Technical-Lessons-S1


محاضرة شاملة في **المناخ الزراعي** لمادة **زراعة عامة — سنة أولى جامعي**، بعقل المكتشف.

## 📄 المحتوى

- **10 فصول** متسلسلة منطقياً: من أهمية المناخ → عناصره → توزيعه → القياس → أثره على النبات → المناخ المحلي → التشخيص → التدخل والتكيّف → التقنيات الحديثة → المراجعة.
- **صندوق «رحلة الاكتشاف»** لكل مفهوم رئيسي (8 خطوات).
- **«احفظ» + «وسيلة تذكر» + «من الميدان» + «اختبر فهمك»** في كل فصل.
- **فصل مراجعة كامل:** بطاقات حفظ، أخطاء شائعة، أسئلة تدريب، خريطة ذهنية، جدول مراجعة متباعدة.

## 🎯 الفئة المستهدفة

طلبة السنة الأولى جامعي — تخصص زراعة / علوم زراعية.

## 🔤 اللغة والمصطلحات

عربية، مع المصطلحات بين قوسين **(English / Français)** عند أول ذكر. أمثلة من السياق الجزائري.

## ✅ مبادئ الأمانة العلمية

- الأمثلة الميدانية بصيغة «في الحقل يحدث غالباً»، لا تجارب شخصية.
- كل اسم أو تاريخ يتبعه **(يُتحقق منه)**.
- الأرقام التقريبية مكتوبة صراحةً كتقريبية.
- لا جرعات أو مقادير مبيدات/أدوية — يُرجَع إلى الملصق أو المختص.

## 🚀 كيفية الاستعمال

1. افتح `مذكرة-المناخ-الزراعي.md` واقرأ الفصول بالتسلسل.
2. راجع فصل **المراجعة** قبل الامتحان باستخدام جدول المراجعة المتباعدة (يوم 1 → 3 → 7 → 14).
3. استعمل بطاقات «احفظ» للمراجعة السريعة.
